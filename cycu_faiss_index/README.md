# cycu_faiss_index

`cycu_faiss_index` 是一個 **FAISS 向量資料庫**，用於儲存 **中原大學資源資料集** 的文本向量，可搭配大型語言模型（LLM）進行語意檢索（Semantic Search）。

---

## 📂 資料夾內容

| 檔案名稱             | 說明 |
|----------------------|------|
| `index.faiss`        | FAISS 的主索引檔，儲存所有向量與索引結構 |
| `index.pkl`          | 對應向量的原始文本與中繼資料（metadata）序列化檔 |


---

## 📖 資料來源

此索引是由 `cycu_resources.txt` 建立，該檔案內容包含：
- **藝文資源**（音樂廳、藝術中心等）
- **學習資源**（圖書館、自學空間、討論室等）
- **心理輔導資源**（諮商中心、心理治療所等）
- **職涯發展**（職涯發展處、學用區等）
- **體育設施**（游泳池、體育館、球場等）
- **餐飲資源**（星巴克、路易莎、麥當勞等）
- **教官室**（各系所教官與聯絡方式）
